Medical areas → Topics

×

Un área reúne varios temas, como una materia que contiene distintas unidades.

Topics → Quizzes

×

Un tema puede incluir varios quizzes para evaluar distintas partes de lo aprendido.

Topics → Study Notes

×

Un tema puede tener varias notas de estudio para resumir o ampliar su contenido.

Auth & Accounts → User profiles

×

Single-table design: cada correo tiene su registro ACCOUNT de unicidad y su registro AUTH y PROFILE con la misma partición USER#sub.

Usuario → User progress

×

Cada estudiante autenticado puede guardar su avance en distintos temas en la tabla User progress con clave USER#sub.

Usuario → Leaderboard

×

Cada estudiante autenticado aparece una sola vez en el ranking general con clave LEADERBOARD y sort key USER#sub.

Usuario → Rate limits

×

El sistema cuenta las solicitudes por minuto para cada usuario con clave RATE#sub y sort key WINDOW#minuto.

Topics → User progress

×

Varios estudiantes pueden avanzar en el mismo tema; cada registro conserva el avance de una persona.
